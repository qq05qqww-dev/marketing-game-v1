============================================================
一、正式上線前本機檢查
============================================================

1. 開啟 PowerShell

2. 進入專案根目錄：

cd C:\Users\User\Desktop\marketing-game-v1

3. 檢查目前檔案狀態：

git status

4. 確認九宮格主檔已覆蓋：

dir frontend\src\views\games\PremiumGridLotteryView.vue

5. 確認前端套件是否存在：

dir frontend\node_modules

如果沒有 node_modules，進入 frontend 安裝：

cd C:\Users\User\Desktop\marketing-game-v1\frontend
npm install

============================================================
二、前端本機啟動檢查
============================================================

1. 進入 frontend：

cd C:\Users\User\Desktop\marketing-game-v1\frontend

2. 啟動前端：

npm run dev

3. 開啟瀏覽器測試三條路線：

正式九宮格玩家頁：
http://localhost:5173/play/a-shop/premium-grid

commonGrid 測試區：
http://localhost:5173/play/a-shop/premium-grid?commonGrid=1

legacyGrid 緊急回退：
http://localhost:5173/play/a-shop/premium-grid?legacyGrid=1

驗收標準：
- 正式頁可以正常開啟
- commonGrid 測試區可以正常開啟
- legacyGrid 回退可以正常開啟
- Console 不應出現 ReferenceError
- Console 不應出現 render function crash
- 畫面不能白屏
- 按鈕與提示卡片不能跑版

============================================================
三、後端本機健康檢查
============================================================

另開一個 PowerShell 視窗。

1. 進入 backend：

cd C:\Users\User\Desktop\marketing-game-v1\backend

2. 安裝套件，如果尚未安裝：

npm install

3. 啟動後端：

npm run dev

4. 檢查後端是否正常啟動：
通常會看到類似：
- Server running on port 3000
- Database connection is healthy
- API ready

5. 使用 PowerShell 測試 API health，如果你的後端有 health endpoint：

Invoke-RestMethod -Uri "http://localhost:3000/api/health" -Method GET

如果沒有 health endpoint，可測試已存在的 campaigns 或 auth 相關 endpoint。

============================================================
四、前端 build 檢查
============================================================

1. 回到 frontend：

cd C:\Users\User\Desktop\marketing-game-v1\frontend

2. 執行正式 build：

npm run build

3. 驗收標準：
- build 必須成功
- 不可出現 Failed to resolve import
- 不可出現 Vue compiler error
- 不可出現 ReferenceError 相關 build 阻斷
- dist 資料夾應正常產生

檢查 dist：

dir dist

============================================================
五、Git commit / push 指令
============================================================

1. 回到專案根目錄：

cd C:\Users\User\Desktop\marketing-game-v1

2. 檢查變更：

git status

3. 加入全部變更：

git add .

4. 建立 commit：

git commit -m "V2.3 premium grid formal deployment handoff"

5. 推送到 GitHub：

git push

6. 如果 push 被拒絕，先確認遠端狀態：

git remote -v

7. 如果需要先拉取遠端更新：

git pull --rebase

再重新推送：

git push

============================================================
六、Render 部署檢查
============================================================

到 Render 後台檢查：

1. Backend service 是否有自動部署
2. Deploy logs 是否成功
3. Environment variables 是否正確
4. DATABASE_URL 是否存在
5. NODE_ENV 是否正確
6. CORS 是否允許前端正式網址
7. Build command 是否正確
8. Start command 是否正確

Render Backend 建議檢查項：

Build Command：
npm install && npx prisma generate && npx prisma migrate deploy

Start Command：
npm start

或依你目前 backend package.json 設定為準。

如果 Render log 出現 Prisma 錯誤：
- 檢查 DATABASE_URL
- 檢查 prisma/schema.prisma
- 檢查 Prisma 版本
- 檢查是否需要 npx prisma generate
- 檢查是否要 migrate deploy

九、rollback 操作流程
============================================================

如果正式頁出現以下問題：
- 白屏
- ReferenceError
- Vue render function crash
- verify 大量失敗
- play 大量失敗
- 中獎結果不回填
- 玩家無法操作
- 商家大量回報異常

第一步：
請先引導使用 legacyGrid：

https://你的正式前端網址/play/a-shop/premium-grid?legacyGrid=1

第二步：
確認是否只有正式頁共用模組異常：

測試：
https://你的正式前端網址/play/a-shop/premium-grid
https://你的正式前端網址/play/a-shop/premium-grid?commonGrid=1
https://你的正式前端網址/play/a-shop/premium-grid?legacyGrid=1

第三步：
如果要回退程式碼：

cd C:\Users\User\Desktop\marketing-game-v1
git log --oneline

找到上一個穩定 commit 後：

git revert <commit-id>

或如果你清楚要回到前一個版本：

git reset --hard <commit-id>

注意：
git reset --hard 會丟棄目前變更，請謹慎使用。

推送回退版本：

git push

如果遠端需要強制覆蓋才可用：

git push --force

注意：
正式專案不建議隨便 force push，除非你確定這是你自己的專案且知道後果。
